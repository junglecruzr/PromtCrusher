Software Blueprinting

Use a saved project blueprint and focused implementation tasks to guide an AI through a complex application one phase at a time.

When to use this mode

Use Quick Prompt for a single request. Use Software Blueprinting for larger projects such as a graphics editor, SaaS product, game, or multi-module application.

The iterative workflow keeps the architecture, roadmap, constraints, and current task together without asking the AI to generate an entire complex application in one response.

Getting started

  1. Select Software Blueprinting from Prompt Mode.
  2. Enter the project name and a concise product summary.
  3. Enter the technology stack, architecture modules, roadmap phases, and coding constraints. Use one item per line.
  4. Select Save Blueprint. The blueprint is stored locally for the next session.
  5. Enter the current phase, task title, detailed task description, target files, and acceptance criteria.
  6. Select Generate Super Prompt to create the focused implementation prompt.

Example: Photocraft

Project summary

A browser-based raster and vector graphics editor with layers, tools, history, and non-destructive filters.

Roadmap phases

Foundation, canvas and layers, brush and eraser tools, history, selections, and WebGL filters.

First task

Create the canvas layer manager with create, delete, reorder, visibility, and normal-blend rendering support.

What the generated prompt contains

  • The project architecture and technology context.
  • The current phase and specific implementation task.
  • Target files and acceptance criteria.
  • Requirements to inspect existing code and preserve unrelated behavior.
  • Testing, validation, edge cases, assumptions, and integration notes.

Local project data

The active blueprint is saved locally at projects/active_blueprint.json. It is excluded from Git and should not contain API keys, passwords, or other secrets.

Update the blueprint as the project architecture changes, then generate one focused task prompt at a time.
