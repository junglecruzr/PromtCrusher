Prompt Framer Help

Choose a framework, describe your idea briefly, and generate a complete standalone Super Prompt.

Basic workflow

  1. Choose the framework that best matches the type of result you want.
  2. Enter a focused one- or two-sentence concept in the subject field. The subject is limited to 200 characters.
  3. Select Generate Super Prompt. Gemini expands the concept using the selected framework.
  4. Review the generated prompt and copy it for use in your target model or development workflow.
  5. Optionally enter improvement instructions and select Enhance Super Prompt.

The enhancement step preserves the original intent, applies your instructions, improves completeness, and checks the prompt against the selected framework.

Available frameworks

RACE — Role, Action, Context, Expectation

General-purpose prompts for defining who the model is, what it should do, the relevant context, and the expected result.

RISE — Role, Instructions/Issue, Steps, Expectation/Example

Useful for guided tasks that need ordered instructions, examples, and a clearly defined outcome.

STAR — Situation, Task, Action, Result

Good for scenario-driven planning, case studies, professional responses, and outcome-focused tasks.

SOAP — Subject, Objective, Action, Plan

Structures a subject or problem into an objective, recommended action, and practical plan.

APE — Action, Purpose, Expectation

A compact framework for straightforward instructions where the action, reason, and expected result matter most.

ERA — Expectation, Role, Action

Starts with the desired result, establishes the model's role, and defines the work required to achieve it.

BAB — Before, After, Bridge

Useful for transformations, marketing concepts, improvement plans, and showing how to move from the current state to the desired state.

TAG — Task, Action, Goal

A simple task-oriented structure for converting a goal into clear actions and deliverables.

RTF — Role, Task, Format

Best for software, writing, research, and other prompts where expertise, assignment, and output format must be explicit.

SOP — Schema, Operations, Proof

Use for reliable JSON, XML, tables, and other structured outputs. It defines the schema, transformation rules, validation checks, examples, and invalid-input behavior.

DEV — Discovery, Engineering, Verification

Use for implementation-ready software prompts. It covers repository discovery, architecture, requirements, code changes, error handling, tests, edge cases, and acceptance criteria.

AGT — Aim, Guardrails, Tools, Workflow

Use for tool-using agents. It defines available tools, permissions, confirmation rules, budgets, stop conditions, error recovery, and evidence-based completion reports.

RAG — Request, Authorities, Grounding

Use for research and retrieval-augmented prompts. It establishes source quality, citation rules, evidence handling, uncertainty, conflicting sources, and protection against fabricated citations.

STORY — Situation, Tension, Outline, Roles, Yield

Use for narratives, screenplays, commercials, and scripts. It develops the premise, conflict, story beats, character arcs, dialogue, pacing, ending, and requested delivery format.

RTF-3D — Interactive Three.js Extension

Use for browser-based 3D applications and simulations. It adds scene architecture, simulation state, animation, camera controls, live metrics, project structure, performance requirements, and validation checks.

IPB — Intent, Palette, Build, Materials, Typography, Boundaries

Use for artistic image and poster prompts. It expands a theme into composition, color, visual hierarchy, materials, print texture, typography, references, and output constraints.

VSB — Vision, Subjects, Blocks, Behavior, Boundaries

Use for cinematic video and commercial prompts. It creates a visual treatment, locked subjects, timed scenes, shot directions, physical behavior, sound design, continuity rules, and negative prompts.

Enhancement workflow

The enhancement action runs after a prompt has been generated.

  • Leave the enhancement field empty to request a general polish and framework review.
  • Enter specific guidance to direct the revision, such as add stronger validation, improve the shot timing, or make the implementation production-ready.
  • The selected framework is sent with the existing prompt so the revision can check its structure.
  • The revised prompt replaces the displayed output and can be copied normally.

Writing better subject inputs

  • Name the main subject and desired result.
  • Include the target medium when it matters: video, poster, Three.js application, report, or code.
  • Include important constraints in the short concept, then use enhancement instructions for later refinement.
  • For framework-specific results, choose IPB for posters, VSB for video, and RTF-3D for interactive Three.js projects.
